# Filler-Free: Live

A real-time AI speech coach for Android. An Agora Conversational AI agent
listens while you speak and interrupts filler words and rambling.

## What you'll build
- Android app (Kotlin, Jetpack Compose)
- FastAPI backend that starts and manages the Agora agent
- [Group/audience coaching with Agora Interactive Live Streaming]
- [MCP tool-calling] 

## Prerequisites
- Agora account with an App ID and App Certificate
- [LLM / ASR / TTS provider keys you use]
- Android Studio, Python [version], two Android devices for group mode [optional]

## Setup
1. Backend: follow [backend-runbook.md](backend-runbook.md)
2. Android app and credentials: follow [setup.md](setup.md)
3. Run the backend, then the app, then start a session.
